# 🏪 CONVENI DELUXE

おにぎり1個から始めるコンビニ経営シミュレーションゲーム。

## 遊び方
- レジに来たお客さんの商品を**長押し**してスキャン → 完了するとお金がもらえる
- 「PC」タブで商品の仕入れ・設備アップグレード・バイトの雇用ができる
- お客さんを待たせすぎると怒って帰ってしまう(忍耐ゲージ)
- 一定確率でVIPのお客さんが来店し、高額購入してくれる
- バイトを雇うとそのレジは自動でスキャン・会計してくれる
- 離席していた間もバイトが自動でお店を回してくれる(最大3時間分)
- セーブはブラウザ内(localStorage)に自動保存。「設定」タブの「リセット」で最初から

## 構成
- `index.html` … 画面とメタ情報
- `css/style.css` … スタイル
- `js/game.js` … ゲームロジック(商品・設備・接客・セーブ処理すべて)
